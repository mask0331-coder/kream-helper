# Kream Helper

kream.co.kr 이용 방식을 커스터마이징하는 개인용 확장 프로그램.
Windows + Chrome, macOS + Safari 양쪽에서 동일한 소스로 사용하는 것을 목표로 합니다.

## 현재 기능
- 설정에서 지정한 URL 패턴을 만족하고, **텍스트 조건 또는 class 조건 중 하나**에 맞는 링크를
  클릭하면 페이지 이동 대신 **팝업 창**으로 엽니다. (kream.co.kr 전용)
  - 기본값: URL이 `/products/`를 포함하면서, 링크 텍스트가 `상품상세`로 시작하거나 **또는**
    class에 `product_card`(검색 결과 상품 카드)가 포함될 때
    (URL 패턴만 쓰면 검색 결과 등 같은 URL 패턴의 링크가 페이지에 너무 많아 오작동했던 적이 있어서,
    텍스트/class 조건을 함께 걸어 특정 링크만 정확히 골라냅니다 — 옵션에서 조정 가능)
  - **텍스트 조건**으로 매칭된 링크만 텍스트에 " (팝업)"이 자동으로 붙습니다. **class 조건**으로
    매칭된 링크(검색 결과 카드처럼 이미지가 들어있는 링크)는 라벨을 붙이지 않습니다 — `textContent`를
    덮어쓰면 이미지 등 자식 요소가 통째로 사라지기 때문입니다.
  - 팝업 창은 하나만 재사용됩니다 (새 링크 클릭 시 기존 창의 내용만 바뀜).
  - 같은 페이지 안에서 옵션/기간만 바꾸는 링크(경로는 그대로, 쿼리스트링만 다름)는 대상에서 제외됩니다.
  - 주문 상세 페이지("판매 진행 중"/"판매 입찰" 등)의 **"상품 상세" 버튼**처럼 `<a href>`가 아니라
    클릭 핸들러로만 이동하는 버튼도 텍스트 조건에 맞으면 팝업으로 엽니다. 원래 탭은 전혀 이동하지
    않고, 별도 팝업 창이 그 페이지를 다시 열어 자동으로 버튼을 눌러 이동합니다(원래 탭이 잠깐
    다른 페이지로 넘어갔다 돌아오는 깜빡임을 막기 위함) — 팝업 창 안에서도 실제 이동이 끝날
    때까지는 화면을 숨겨서 중간 전환이 안 보이게 합니다(새 창을 여는 최초 로딩 여백은 브라우저
    자체 특성이라 어쩔 수 없습니다).
- **어떤 사이트에서든** 텍스트를 드래그 선택하고 단축키(기본 `Ctrl+Q`)를 누르면, 새 탭에서
  `kream.co.kr/search?keyword=<선택한 텍스트>` 로 이동합니다.
- 상품 상세 페이지(`/products/*`)에서는 화면 상단 중앙에 **제품명 복사 / 품번 복사 / 링크 복사** 버튼이 뜹니다.
  이 버튼은 상품 상세 페이지를 벗어나면(예: 판매/보관 신청 흐름으로 넘어가는 `/sell/...`) 자동으로
  사라집니다 — SPA 방식으로 페이지를 넘나들어도 경로를 계속 확인합니다.
- 상품 상세 페이지의 "거래 및 입찰 내역" 패널을 열면, **"최근 시세" 옆에 최근 30일 거래량**을 계산해서
  보여줍니다. "체결 거래" 탭에서만 동작하고(판매 입찰/구매 입찰 탭에서는 관여하지 않음), 화면에
  보이는 행(사이트 자체 옵션 필터를 따름)을 기준으로 집계합니다. 이 패널은 클릭형 "더보기" 버튼이
  아니라 스크롤로 더 불러오는 방식이라(사이트가 관리하는 `.drawer__content`의 scrollTop을 직접
  움직여 트리거), 30일 이전 데이터가 나올 때까지 자동으로 계속 내립니다 (인기 상품은 몇 초 걸릴 수
  있음). 한 번 계산이 끝나면 같은 드로어에서는 다시 자동 계산하지 않아서, 계산 후 사용자가 직접
  스크롤해서 과거 내역을 살펴봐도 방해하지 않습니다.
- 상품 상세 페이지의 "판매"/"구매하기" 버튼 **크기를 동일하게 맞추고**(원래는 부모 레이아웃이
  의도적으로 다르게 배치해서 크기가 달랐음), **둘 다 볼드를 빼고 색을 칠합니다**(판매=주황,
  구매하기=파랑 — 원래는 판매만 색이 있고 구매하기는 흰색이었음).
- 크림 사이트 전체의 **브라우저 탭 아이콘(파비콘)을 바이낸스 컬러 계열 주황색 별 모양**으로
  바꿉니다.

## 설치 (개발자 모드)
1. `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 폴더(`kream-helper`) 선택
4. kream.co.kr 접속 후 상품 링크 클릭해서 팝업으로 뜨는지 확인

## 설정 변경
확장 프로그램 아이콘 우클릭 → **옵션** (또는 `chrome://extensions` → Kream Helper → 세부정보 → 확장 프로그램 옵션)
- 팝업으로 열 링크 패턴 (줄바꿈으로 여러 개 추가, `/정규식/` 형식 지원)
- 링크 텍스트 조건 / 링크 class 조건 (텍스트 조건 또는 class 조건 중 하나만 맞아도 팝업 대상.
  둘 다 비워두면 URL 패턴만으로 판단 — **비추천**: 페이지 전체가 오작동할 수 있음)
- 팝업 창 크기

## 검색 단축키 변경
기본 단축키는 `Ctrl+Q`입니다. 다른 확장 프로그램과 겹치거나 원하는 조합으로 바꾸려면:
`chrome://extensions/shortcuts` 접속 → Kream Helper 항목에서 직접 재지정

## 코드 수정 후 반영
`chrome://extensions`에서 Kream Helper 카드의 새로고침(⟳) 버튼 클릭 → kream.co.kr 페이지도 새로고침

## Safari(Mac)에서 사용하기
이 저장소를 Mac에 clone한 뒤:

```bash
xcrun safari-web-extension-converter /path/to/kream-helper
```

으로 Xcode 프로젝트를 생성하고, Xcode에서 빌드/실행 → Safari 환경설정 → 확장 프로그램에서 활성화합니다.
Xcode가 생성하는 프로젝트 파일은 `.gitignore`로 제외되어 있으니, 코드(`content.js`, `options.*`, `manifest.json`)를
수정할 때마다 이 저장소에만 커밋하고 Mac에서는 `git pull` 후 변환 명령을 다시 돌리면 됩니다.
